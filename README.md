# QazaqSign AI

PWA-переводчик жестового языка через камеру: жест → субтитры на русском и казахском + озвучка.
Всё работает в браузере на устройстве — без сервера, видео никуда не отправляется.

> Мы не носители жестового языка, поэтому модель обучена на открытом датасете **Slovo**
> (русский жестовый язык, 1001 класс, ~200 носителей). Казахский — это перевод распознанного
> русского слова, а не казахский жестовый язык.

## Как это работает

```
камера ─► MediaPipe HandLandmarker ─► 21 точка × до 2 рук на кадр
        ─► буфер последних 1.5 с ─► нормализация + ресемплинг к 32 кадрам ─► [32 × 132]
        ─► 1D-CNN (ONNX, onnxruntime-web) каждые 200 мс ─► вероятности слов
        ─► правило «засчитать слово» ─► субтитры RU / KK ─► speechSynthesis
```

### 1. Данные
- `data/slovo_mediapipe.json` — точки рук MediaPipe по кадрам для каждого видео Slovo (только участок жеста `begin..end`, кадры без рук выкинуты).
- `data/annotations.csv` (TSV) — `attachment_id, text, user_id, height, width, length, train, begin, end`.
- Особенности, выясненные при разведке:
  - `hand 1` / `hand 2` **не** означают левую/правую руку и меняются местами внутри видео, поэтому руки раскладываются по положению в кадре (см. ниже).
  - Класс `no_event` есть в аннотациях, но его точек в JSON нет. Вместо него обучается класс **`_other`** — жесты из ~300 других слов Slovo + синтетический «покой» (неподвижные руки). Он учит модель отвечать «это не слово из словаря».
  - Из 20 кандидатов (привет, спасибо, врач, банк…) в Slovo точно нашлись 7, остальные заменены близкими словами или дополнены полезными (сегодня, имя, кто?, бумага…).

### 2. Признаки (`training/features.py` ≡ `web/src/features.js`)
1. Координаты в пиксели: `x·W, y·H, z·W` (кадр может быть портретным или альбомным).
2. Раскладка рук по слотам: две руки — слот 0 левее в кадре; одна рука — в слот, чья последняя x запястья ближе.
3. Ресемплинг последовательности к **32 кадрам** (ближайший кадр).
4. На руку 66 признаков: 21×3 точки относительно запястья, делённые на размер ладони (запястье → основание среднего пальца); положение запястья относительно центра окна (траектория); флаг присутствия. Нет руки — нули. Итого `[32, 132]`.

Python и JS-версии сверяются автоматически: `npm run test:features` (расхождение ~1e-5).

### 3. Модель (`training/train.py`)
- 1D-CNN: свёртка 1×1 → 3 остаточных блока Conv1d(k=5)+BN+ReLU → mean+max pooling → MLP. ~300 тыс. параметров, 1.2 МБ ONNX, инференс < 1 мс.
- Аугментация: зеркалирование (левая ↔ правая рука, фронтальная камера), поворот ±15°, масштаб, шум точек, дрожание руки, обрезка по времени (окно в браузере может захватить жест не целиком), пропуски детекции.
- **Фаза A** — пул из 32 слов + `_other`; оценка 5-fold кросс-валидацией по носителям внутри train (~15 видео на слово — точнее, чем 5 тестовых). Автоотбор 12 слов по F1; «привет», «вода», «ждать» включены принудительно для демо.
- **Фаза B** — переобучение на 12 словах + `_other`, проверка на официальном тесте (`train=False`), экспорт `web/public/model/sign_model.onnx` + `labels.json` (рус. слово, каз. перевод, точность).
- Обучение на CPU: ~8 минут целиком.

| | значение |
|---|---|
| Точность на тесте (12 слов + `_other`) | 73% |
| … на носителях, которых не было в train | 72% |
| Надёжные слова (CV ≥ 80%) | плохо, сегодня, ещё нет, кто?, добро пожаловать, имя, помочь |
| Слабые | ждать (CV 0%), вода (47%) |

Отчёты: `training/reports/` (точность по словам и confusion matrix в CSV).

### 4. Сайт (`web/`, Vite + vanilla JS)
- MediaPipe HandLandmarker (GPU, при ошибке — CPU) рисует точки и линии рук поверх видео; переключение фронтальной/тыльной камеры.
- `recognizer.js`: окно 1.5 с, инференс каждые 200 мс. Слово засчитывается, если оно не `_other`, уверенность ≥ **0.6** **3 раза подряд** и оно не равно предыдущему. Нет рук ≥ 1 с — конец фразы. Порог 0.6 выбран по тесту: при нём ошибочные слова ~0%, ложные срабатывания на незнакомых жестах ~12% на одно окно (правило «3 подряд» снижает их дальше).
- Субтитры RU + KK, «Очистить», «Озвучить» (ru-RU; kk-KZ — если в системе есть казахский голос).
- «Словарь» — доступные слова с меткой качества (надёжно / средне / слабо).
- «Отладка» — топ-3 предсказания с вероятностями, FPS, ползунки порога и числа подтверждений.
- PWA: `manifest.json`, иконки, service worker (офлайн-кэш), мета-теги iOS (`apple-mobile-web-app-capable`, standalone) — «На экран Домой» открывается как приложение.
- Все модели и wasm отдаются с того же домена (без CDN).
- Если onnxruntime-web не запускается (на телефонах бывает `RangeError: Out of memory` — не хватает памяти на второй wasm-модуль рядом с MediaPipe), модель выполняется запасным движком `web/src/tinyonnx.js`: он читает тот же `.onnx` и считает на чистом JS (~20–30 мс на прогон). Активный движок виден в режиме отладки.

## Запуск

```bash
# обучение (Python 3.11+, нужны data/slovo_mediapipe.json и data/annotations.csv)
pip install numpy pandas onnx onnxruntime
pip install torch --index-url https://download.pytorch.org/whl/cpu
python training/prepare_data.py   # JSON 1.2 ГБ -> data/cache/landmarks.npz (потоково, ~45 с)
python training/train.py          # обучение, отчёты, экспорт в web/public/model/

# сайт
cd web
npm install
npm run dev            # http://localhost:5173 (камера работает на localhost)
npm run test:features  # сверка JS-признаков с Python
npm run test:model     # onnxruntime-web и tinyonnx.js дают одинаковые вероятности
npm run build          # -> web/dist
```

Чтобы открыть dev-сервер с телефона, нужен HTTPS (iOS не даёт камеру по http) — проще всего задеплоить на Vercel.

## Деплой на Vercel

Конфиг — `web/vercel.json`. Сборка сама скачает модель MediaPipe (`scripts/copy-assets.mjs`).

- Через сайт: Import Project → **Root Directory: `web`** → Deploy.
- Через CLI: `cd web && npx vercel --prod`.

Vercel выдаёт HTTPS-домен — на iPhone откройте его в Safari → «Поделиться» → «На экран Домой».

## Ограничения
- 12 слов, по 15 обучающих видео на слово — точность ограничена данными.
- Жесты РЖЯ из Slovo; для казахского жестового языка нужен свой датасет, пайплайн при этом не меняется.
- Модель видит только руки (без лица и позы), поэтому жесты, отличающиеся мимикой или местом у тела, путаются.
